# Changelog

## 0.1.1 - 2026-08-29

- Rename the first layer to `30-second learning brief` and add the required `End of 30-second learning brief` boundary before normal agent detail.
- Add Quiet, Coach, and Deep learning modes with Quiet as the default.
- Add project-grounded Learning Diffs and a six-stage gradual handback ladder.
- Add open-response, prediction, and code-reading practice with guidance hidden until an attempt.
- Add delayed recall and evidence-backed misconception guidance.
- Add session-only, private-project, and shared-project privacy modes.
- Add local recall-state tooling, behavioral eval scenarios, and universal agent installation guidance.

## 0.1.0 - 2026-08-29

- Add the two-layer response contract with a 30-second summary first.
- Add project learning profiles, records, review modes, and privacy boundaries.
- Add structured lesson validation and a self-contained HTML renderer.
- Add quizzes, flow views, optional Three.js views, and offline fallbacks.
- Add Codex plugin and repository marketplace packaging.
