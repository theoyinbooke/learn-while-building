Ship the code. Keep the understanding.

A learning layer for people building real software with coding agents. It turns project decisions into clear mental models, useful practice, and knowledge that returns when you need it.

Install the skill View the source

30-second learning brief

The validation fix moves the check to the point where data enters the system. That matters because every caller now receives the same protection. The reusable idea is to enforce important rules at a shared boundary. The regression test passes. Production behavior has not been verified yet.

End of 30-second learning brief

The agent's regular detailed response begins below this clear boundary.

Learning comes from the work itself.

The skill reads the active request, project evidence, tests, and the learner's chosen objective. It explains only the decisions that build a reusable mental model. The software outcome stays first.

Choose how much teaching you want.

Quiet

Get the maximum 30-second learning brief, then the normal task response. No extra questions unless the work needs one. This is the default.

A diff for your understanding.

The Learning Diff connects a code change to what you can reason about next. It is grounded in the files, tests, and behavior from your project.

  1. 1
    Software change
    What changed in the actual project.
  2. 2
    Why it works
    The causal explanation, not only a description.
  3. 3
    Mental model
    The idea that transfers to nearby work.
  4. 4
    Project trace
    The files, tests, and observations behind the claim.
  5. 5
    Practice and limits
    What to predict or modify, and what is still unverified.

Your project. Your memory choice.

Conversation access is limited to what the host supplies. Durable learning is optional, scoped to one project, and never requires storing a full transcript.

Session-only

Adapts inside the current conversation and writes no learning state to disk.

Private-project

Stores compact state in a locally ignored folder inside the checkout.

Shared-project

Stores reviewable learning records under docs/learning/ when collaboration is intentional.

One command to start.

Install the portable skill globally in compatible coding agents. The repository also includes Codex plugin marketplace packaging.

npx skills add theoyinbooke/learn-while-building --skill learn-while-building --global
